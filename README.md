## 🎯 Overview  
Forecasting hourly energy use (**AEP_MW dataset**) with a full pipeline:  
from 🔍 exploration → 🤖 modeling → 📊 evaluation   

## 🚀 Key Features  
- 📊 **EDA** → trends, seasonality, stats  
- 📈 **Stats Models** → ARIMA, SARIMA, Prophet, TBATS  
- 🤖 **ML Models** → XGBoost, LGBM, CatBoost, RF  
- 🧠 **DL Models** → LSTM, GRU, RNN, CNN-LSTM, Transformer  
- ⚙️ **Extras** → feature eng., tuning, explainability  
- 🎨 **Visulaization** → clear + interactive plots

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sampavi01/Advanced_Time_Series_Forecasting.git
   cd Advanced_Time_Series_Forecasting
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch Jupyter**
   ```bash
   jupyter notebook
   ```
